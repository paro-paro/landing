**Blockchain** is a shared database that functions as a ledger for recording buy-sell operations or any other transaction. It consists of a set of entries stored in a shared online database where operations, amounts, dates, and participants are recorded using codes.

By using cryptographic keys and being distributed across many computers (people), it offers security advantages against manipulation and fraud. A modification in one of the copies would be useless, as the change must be made in all copies because the database is open and public.
